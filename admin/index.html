Every text, price, photo, timetable and contact detail on the site can be changed here. Press Save, then open the site to check it.

Preview mode. The site is hosted on GitHub Pages, which has no server, so your edits are saved in this browser only and visitors still see the published site. Use Backup & settings → Export to move them to another browser. Connecting the site to the free Cloudflare server («الربط») publishes edits to every visitor.
